You are a senior C# graphics engineer. Redesign an existing map renderer from polygon shapefile rasterization to a grid/tiles control system optimized for dynamic war/occupation mechanics and GPU rendering. Maintain API compatibility where possible, but prefer clarity and performance.

Context (current system)

Vector shapefiles (CShapes-2.0) are filtered/rasterized once for a fixed year (1950) to an int[,] mask; rendering then colors pixels per country and draws borders by checking neighboring mask cells. See:

PoliticalBorderManager.CreatePoliticalMask(..) and strict date filtering/rasterization path

PoliticalTileManager tile assembly, mask usage, and optimized per-pixel render incl. border passes in RenderPoliticalTileOptimized(..)

Spatial index for country lookup built from clean cache: PoliticalSpatialIndex.BuildIndex(..)

Selection/state overlays & zoom thresholds live in HybridMapManager and PoliticalTileManager

We need fast, frequent territorial updates (front lines, occupation), which are cumbersome with polygon ops.

High-level goals

Authoritative grid: Replace polygon-first rendering with a world control grid (uniform cells) as the primary source of truth for who controls each cell.

Dynamic updates: War/occupation changes update cell ownership in real time (single cells, flood fills, fronts).

GPU pipeline: Render grid via GPU (compute + texture or fragment shader) with CPU fallback. Update only dirty tiles.

Tiled, LOD-aware: Partition world into fixed-size tiles (e.g., 512×512 cells), support mipmaps/LODs for zoom.

Minimal churn: Keep the existing spatial index for click/country lookup, keep color palette mapping, keep HybridMapManager and the tile cache shape, but swap the guts to consume grid data.

Deliverables

Integration patches for:

HybridMapManager to keep events and selection flow the same

Shader sketch (fragment shader path)
// Uniforms: sampler2D controlTex; is 1 texel = 1 cell in the current LOD tile
//           sampler1D paletteTex; uvec4 selection (selectedId, stateId, flags, 0)
vec4 sampleColor(ivec2 cell) {
    int id = texelFetch(controlTex, cell, 0).r; // integer ID
    return texelFetch(paletteTex, id, 0);       // RGBA
}

bool isBorder(ivec2 c) {
    int id = texelFetch(controlTex, c, 0).r;
    if (id == 0) return false; // water isn't drawn as land border
    return any(bvec4(
      texelFetch(controlTex, c + ivec2( 1, 0), 0).r != id,
      texelFetch(controlTex, c + ivec2(-1, 0), 0).r != id,
      texelFetch(controlTex, c + ivec2( 0, 1), 0).r != id,
      texelFetch(controlTex, c + ivec2( 0,-1), 0).r != id));
}

void main() {
    ivec2 cell = ivec2(floor(vCellCoord)); // precomputed screen->cell mapping
    int id = texelFetch(controlTex, cell, 0).r;
    vec4 baseColor = texelFetch(paletteTex, id, 0);

    bool border = isBorder(cell);
    bool selectedNeighbor =
         (id == uSelectedId) ||
         any(bvec4(
            texelFetch(controlTex, cell + ivec2(1,0),0).r == uSelectedId,
            texelFetch(controlTex, cell + ivec2(-1,0),0).r == uSelectedId,
            texelFetch(controlTex, cell + ivec2(0,1),0).r == uSelectedId,
            texelFetch(controlTex, cell + ivec2(0,-1),0).r == uSelectedId));

    vec4 borderColor = selectedNeighbor ? vec4(1,1,1,1) : vec4(0,0,0,1);
    outColor = border ? borderColor : baseColor;
}
